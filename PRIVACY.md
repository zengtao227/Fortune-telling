# Privacy Policy

Effective date: 2026-08-04

Mystic Compass is designed to work entirely offline.

## Data entered by the user

The astrology form may contain a birth date, birth time, and birth city. The app uses those values locally to calculate simplified Sun, Moon, and Rising signs.

The app does not transmit these values to the developer or any third party. It does not request device location.

## Local storage

Birth details are not stored by default. If the user enables **Remember on this device**, the values are stored in the app's local AsyncStorage area (or browser localStorage on the web build). This storage is not encrypted and should not be enabled on a shared device.

The user can delete the saved values using **Clear local data**. Android application data can also be removed through system settings or by uninstalling the app.

## Network and third parties

The F-Droid Android build:

- blocks Internet permission;
- disables Expo remote updates;
- contains no ads, analytics, crash-reporting SDK, account service, push notification service, or remote API.

## Children

The app does not knowingly collect or transmit personal information from children. Local form data remains under the control of the device user.

## Contact

Privacy questions and security reports may be filed in the GitHub repository issue tracker.
