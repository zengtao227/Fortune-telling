# Building

## Supported build environment

- Linux x86_64
- Node.js 22.13.x
- npm 11.5.x
- JDK 17 (or the JDK version required by the Expo SDK 57 Gradle template)
- Android SDK Platform 36
- Android Build Tools 36.x

Set `ANDROID_HOME` and ensure `platform-tools` and `build-tools` are on `PATH`.

## Verification

```bash
npm install
npx expo-doctor
npm run lint
npm test
```

## Android release APK

```bash
bash scripts/build-fdroid.sh
```

Output:

```text
android/app/build/outputs/apk/release/app-release.apk
```

The APK generated by this command is unsigned. F-Droid signs its own builds.

## Manual equivalent

```bash
export CI=1
export EXPO_NO_TELEMETRY=1
npm install
npm run verify
npx expo prebuild --clean --platform android --no-install
cd android
./gradlew --no-daemon assembleRelease
```

## Permission check

```bash
aapt2 dump permissions android/app/build/outputs/apk/release/app-release.apk
```

The F-Droid candidate must not contain `android.permission.INTERNET`. `android.permission.VIBRATE` may be present because haptic feedback is implemented locally.

## Dependency lock

Before tagging a release, regenerate and commit `package-lock.json` with the pinned Node/npm versions, then run the build twice in fresh workspaces. Differences must be investigated before requesting reproducible-build status.
